Grav 2.1 serves every page as Markdown. Add `.md` to a URL, or send `Accept: text/markdown`, and an agent gets clean text instead of HTML.

===

## Predictable structure

When every section is a typed block, an agent can add a pricing table without guessing at markup.

## One API for people and agents

The admin and the MCP server talk to the same API with the same permissions.
